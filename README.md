# Hardcoding PRO: GitHub для вайбкодера

Готовый шаблон, чтобы начать работать с проектами через GitHub без ручного изучения Git-команд.

## Что здесь есть

- `PROJECT.md` - смысл и цель проекта
- `TASKS.md` - текущие задачи
- `AGENTS.md` - правила для Codex / Claude Code
- `.gitignore` - защита локальных и секретных файлов
- `.github/workflows/validate.yml` - автоматическая проверка проекта
- `scripts/validate_project.py` - простая проверка структуры и случайных секретов

## Как использовать

1. Нажми **Use this template**.
2. Создай свою копию репозитория.
3. Открой проект в Codex / Claude Code.
4. Дай агенту промпт из гайда Hardcoding PRO.
5. Дальше агент сам ведёт ветки, коммиты, Pull Request, проверки и main.

Тебе не нужно запоминать Git-команды.
